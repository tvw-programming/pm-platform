# Keyboard Shortcuts

Press **`?`** anywhere in the app to open the shortcuts overlay.

![Keyboard shortcuts overlay](/screenshots/keyboard-shortcuts.svg)

---

## Navigation

| Shortcut | Action |
|----------|--------|
| `G` then `D` | Go to Dashboard |
| `G` then `T` | Go to Tasks |
| `G` then `S` | Go to Sprints |
| `G` then `R` | Go to Roadmap |
| `G` then `C` | Go to Chat |
| `G` then `I` | Go to Ideas |
| `G` then `F` | Go to Feedback |

---

## Global

| Shortcut | Action |
|----------|--------|
| `⌘K` | Command palette — search tasks, navigate, run actions |
| `⌘N` | Create new task |
| `⌘J` | Quick-switch project |
| `?` | Show/hide keyboard shortcuts overlay |

---

## Tasks

| Shortcut | Action |
|----------|--------|
| `⌘N` | New task |
| `⌘K` | Search / jump to task |
| `V` | Toggle board / list view |
| `F` | Open filter panel |
| `⌘A` | Select all tasks (filtered) |
| `Esc` | Deselect / close panel |

---

## Task detail (with a task open)

| Shortcut | Action |
|----------|--------|
| `P` | Set priority |
| `S` | Set status |
| `L` | Add label |
| `⌘I` | Assign to me |
| `Esc` | Close detail drawer |

---

## Chat

| Shortcut | Action |
|----------|--------|
| `Enter` | Send message |
| `⇧Enter` | New line in message |
| `⌘E` | Toggle Event Mode |
| `/` | Focus chat input / search templates |

---

## Notes

- On **Windows** and **Linux**, use **`Ctrl`** in place of **`⌘`** (Command)
- Shortcuts are inactive while the cursor is inside a text input
- Two-key navigation shortcuts (`G` then letter) have a 1-second window between keys
